# Gemtrack — правила для агентов

## Сборка фронта = развёртывание

`dash/dist` — живая панель. Работающий сервер (`rig/server/index.ts`, `@fastify/static`)
отдаёт его прямо с диска, без перезапуска; папка в `.gitignore`. Любая сборка в `dash/dist`
сразу меняет то, что видит владелец.

- Проверочные сборки — только `cd dash && npm run build`: она пишет в
  `node_modules/.verify-dist` (так же собирает CI).
- `npm run deploy` (сборка в `dash/dist`) — **развёртывание**. Только после мёржа, из `master`
  (во временной копии репозитория, `git worktree`), и **только с отдельного разрешения
  владельца** в чате. Не вместе с проверками, не с ветки.
- Показ (`VITE_DEMO=1`) собирается в `dash/dist-demo` — к живой панели не относится.

## Прочее

- Живые действия (чтение Steam и площадки, входы по QR, перезапуск панели, развёртывание) —
  только по отдельному «да» владельца.
- Мёрж — только по явному «мёрдж #N» владельца.
- Репозиторий публичный: ни секретов, ни личных данных (steamid, суммы, id) — в коммиты,
  описания PR и вывод не пишем.
