# Сборка показа

Панель без сервера: данные берутся из снимка, вшитого в саму сборку.
Поток не открывается, ни один запрос наружу не уходит, кнопка «запустить»
отвечает отказом. Нужна ровно для одного — дать ссылку, по которой
интерфейс можно посмотреть, не заводя аккаунта и не подпуская чужого
человека к живой сессии Steam.

```bash
VITE_DEMO=1 npx vite build      # соберётся в dist-demo/
```

Получится папка со статикой, которую можно положить куда угодно.
Пути относительные — работает и из подпапки.

## Что в снимке и чего в нём нет

Снимок обезличен при съёмке:

```
steamid       подменён на 7656119800000000
номера вещей  заменены на demo-<число>
файл сессии   назван session.json
```

В сборке нет и быть не может: ключей Steam и OpenDota, файла сессии,
базы матчей, путей с диска. Проверено поиском по готовому файлу.

## Обновить снимок

Поднять рабочий сервер и снять заново — скрипт съёмки лежит в истории
команд; он ходит по `/api/state`, `/api/accounts`, `/api/settings`,
`/api/graph`, `/api/tree`, `/api/queue`, чистит и кладёт в
`src/demo/snapshot.json`.

## Чего в показе нет

Живого инвентаря, отправок, привязки аккаунта, подбора паузы по замерам.
Всё это требует сервера и настоящей сессии.
