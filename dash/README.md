# Дашборд Gemtrack

Собран с нуля по osint-catalog.xyz. Числа взяты из их сборки, а не на глаз:

```
фон            #0a0a0a + шум 12 % с наложением overlay, плитка 160 px
поверхность    белый 1 %, на наведении 2 %
границы        белый 6 %, на наведении 12 %
углы           прямые, --radius: 0
шрифты         Geist, Geist Mono
подпись        12 px / 500 / -0.012em, НЕ капсом
управление     высота ровно 40 px
контейнер      max-w-5xl, зазор плитки 2
тень           только у плавающих элементов: 0 8px 26px #00000029
```

Тема — нейтральная тёмная shadcn (те же oklch, что у референса).
Смысловые цвета (идёт / внимание / стоп) взяты из их набора chart-*,
потому что каталогу состояние показывать нечем, а дашборду есть.

Данные приходят одним потоком SSE с `/api/stream`. Ничего не опрашиваем.

```bash
npm run dev     # разработка на 5173, данные с 4322
npm run build   # проверка типов и сборка — НЕ в dist (node_modules/.verify-dist)
npm run deploy  # сборка в dist — её сразу отдаёт сервер на 4322: это развёртывание
```

Старая панель лежит в `_legacy/panel-2026-08-21` и референсом не является.
