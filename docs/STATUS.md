## 1. Коротко

Проект начинался с двух блокеров. **Оба сняты**, но не так, как ожидалось.

**Блокер 1 — считается ли голый гем без сокета.** Считается. Проверено замером,
цена ответа четыре цента. Artificer's Chisel, который был главным узким местом
всей затеи, не нужен вовсе.

**Блокер 2 — кто покупает высокие счётчики.** Снят вашим решением: сбыт
придумаете сами, техническая часть не должна на него оглядываться.

Дальше работа ушла в неожиданную сторону: выяснилось, что **все числа проекта
были неверны**. Не приблизительны — именно неверны, причём в обе стороны. День
ушёл на то, чтобы построить собственный источник данных вместо чужих выгрузок.

## 2. Что доказано замерами

Каждый пункт оплачен реальной отправкой в Game Coordinator и подтверждён
диффом инвентаря. Ни одного вывода «по логике».

### 2.1 Голый гем набирает счётчик

Куплен `Spectator: Alliance` со счётчиком 2. Отправлен один матч Alliance.

```
голый гем                    2 → 3
три предмета с сокетом       0 → 1
все прочие гемы              не шелохнулись
```

Одно сообщение подняло **четыре объекта с двумя разными базами**. Значит
селектора по значению нет, а сокет для начисления не нужен.

**Следствие для экономики:** коллекция собирается россыпью из гемов по три цента.
Прежний план упирался в чиселы по $1.07 при обороте три штуки в сутки — этого
ограничения больше нет.

### 2.2 Гем считает свою сущность, а не лигу

В лиге 14389 у Empire один матч, у NaVi десять. Сожгли матч Empire из этой лиги:

```
Empire   1 → 11
BZZ      0 → 10
NaVi     5 → 5      ← не двинулся
```

Будь охват лиговым, NaVi обязан был тикнуть. Потолок гема — матчи его сущности
и ничего сверх.

### 2.3 Аккаунтный журнал GC не истекает

Пять матчей NaVi, сожжённых 26 часами ранее, отправлены повторно: пять ответов
7204, ноль обновлений, счётчик неподвижен. Доить одну сущность бесконечно нельзя.

### 2.4 `league_id` обязателен

Матч `8003261364`, две попытки подряд:

```
без league_id  →  7204, 0 байт, счётчик неподвижен
с league_id    →  ОБНОВЛЕНО, 507 байт, Alliance 1→2, голый гем 3→4
```

GC молча отвергает сообщение без второго поля. Это блокировало 26 гемов-игроков
из 53: эндпоинт OpenDota, из которого строились их списки, поля `leagueid`
не содержит вовсе.

### 2.5 `dup` не означает «сожжён»

`CMsgUpgradeLeagueItemResponse` — **пустое сообщение**, полей нет ни одного
(проверено по протоколу Valve). Поэтому 7204 без `msg 26` означает только
«счётчика не будет», а причина может быть любой.

Тот самый матч `8003261364` вернул `dup` и **остался целым** — засчитался со
второй попытки. Код помечал такие матчи сожжёнными навсегда.

**Подтверждением засчёта считается только `msg 26`.**

## 3. Что построено

### 3.1 Локальная карта матчей

Главный результат дня. Собственный источник данных вместо чужих выгрузок.

```
vmatch     305 427 матчей     матч → лига, обе команды, время, тип лобби
  valve    240 433            обход Steam Web API по 2106 лигам
  mirror    64 994            добор из OpenDota там, где Valve режет
vplayer  3 010 689 связей     матч → account_id
vleague      2 106 лиг        состояние обхода, для возобновления
```

База 230 МБ. **Запас любого гема считается локальным SQL** — внешние API
не нужны ни для перемера, ни для очередей, ни для новых гемов.

**Почему два источника, а не один.** Каждый неполон по-своему:

| Источник | Матчей | Природа |
|---|---|---|
| Steam Web API | 240 433 | первоисточник, но **потолок 500 матчей на лигу** |
| OpenDota | 251 443 | зеркало, потолка нет, но знает не всё |
| **объединение** | **305 427** | больше каждого на 20 % |

Потолок Valve проверен и обхода не имеет: `total_results` приходит равным 500
там, где матчей 7645; курсор ниже последнего даёт пусто; `date_min`/`date_max`
игнорируются целиком — три разных окна вернули одну и ту же страницу.

После сведения **разрыв с зеркалом равен нулю**.

### 6.1 Механика — один вопрос

**Переживает ли счётчик извлечение чиселом.** Единственный неотвеченный.
Рынок намекает, что да, но с тех пор как выяснилось, что голый гем сам умеет
набирать, рыночные лоты доказательством не служат.

Цена: Artificer's Chisel около $1.07, необратимо. Если счётчик переживает —
меняется стратегия: можно крутить россыпь по три цента и собирать ценность
в один предмет.

### 6.2 Данные — необязательное

**STRATZ, третий источник.** После сведения двух даёт около 3 %: по Ohaiyo
1916 против наших 1849, по Alliance 2560 против 2483. Цена — постраничный обход
53 сущностей, порядка тысячи запросов. Семьдесят матчей на гем не меняют
ни одного решения о закупке. **Не рекомендую.**

**Три гема без сущности** — `CaspeRRR`, `VeRsuta`, безымянный. Работа руками
по Liquipedia, не по API.

**`D2L`** отдал ноль — похоже, неверный `entity_id` лиги.

## 7. Открытый вопрос по интерфейсу

Ради него документ и написан.

### Что было решено раньше

```
одно полотно, без вкладок-режимов
1920 × 1080
интерфейс на английском
пять вкладок-видов над одним набором: Table · Cards · Graph · Bundles · Burn log
справа живой рельс: очередь, следующие сущности, лента событий
визуальный язык shadcn/ui, как у osint-catalog.xyz
```

### Что изменилось с тех пор

Решение принималось **до** того, как выяснились три вещи:

1. **Чиселы не нужны.** Раньше каждый гем требовал сокета, и закупка была
   ограничена оборотом чиселов — три штуки в сутки. Теперь коллекция собирается
   россыпью, и «что купить» стало вопросом на несколько долларов, а не на месяц.

2. **Разброс цен схлопнулся.** У первой десятки $/1000 от 0.012 до 0.016.
   Выбирать между гемами почти не из чего — берутся все. Значит **каталог как
   инструмент выбора обесценился**: сортировка по цене тысячи больше ничего
   не решает.

3. **Запас стал большим и честным.** 44 653 матча в объединении. При паузе
   в секунду это 12 часов непрерывной работы. Прожиг превратился из
   пятиминутного эксперимента в **длительный процесс**, за которым надо следить.

### Вопрос

Первый экран — про что?

**Вариант А, как решили раньше.** Каталог главный, прожиг в рельсе справа.
Логика: сначала собери состав, потом жги.

**Вариант Б.** Прожиг главный, каталог вкладкой. Логика: состав собирается один
раз за десять минут и стоит четыре доллара, а потом двенадцать часов идёт
прожиг, и смотреть надо на него.

**Вариант В.** Первый экран — не то и не другое, а **состояние**: сколько
осталось всего, что жжётся сейчас, сколько до конца, что тикнуло за последний
час. Каталог и очередь — вкладками.

Моё мнение: раньше я склонялся к А, теперь склоняюсь к Б или В. Каталог из 53
позиций, где все стоят три цента и различаются на четверть процента, — это
таблица, которую посмотрят один раз. А прожиг на 44 тысячи матчей — то, с чем
живут.

Но это ваш инструмент и ваш сценарий. Скажете — сделаю как решите.
