# Этап 1: каркас новой панели за `?ui=v2` — план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Цель:** в той же сборке `dash` появляется новая панель по адресу `/?ui=v2`: рейка из шести пунктов, верхняя полоса, плавающий пульт с «Накрутить» через окно подтверждения, колокольчик тревог, служебные состояния, клавиатура и фокус. Экраны внутри — честные заглушки: их наполняют этапы 2.1–2.6. Старая панель по `/` работает ровно как раньше.

**Как устроено:** новый код живёт в `dash/src/v2/` и стилизуется своим файлом `v2.css`, где **все правила внутри корня `.v2`** — старый `index.css` не трогается и не перебивается. Логику пульта и тревог не пишем заново: чистые функции переезжают из `views/Work.tsx` в `lib/worker.ts` без изменений, и их зовут обе панели.

**Стек:** React 19, Vite 6, Tailwind 4, lucide-react — без новых зависимостей.

**Спецификация:** `docs/superpowers/specs/2026-10-03-gemtrack-redesign-design.md` — §3 (правила), §4 (каркас), §5.7 (окна и состояния), §8 (карта файлов), §9 (проверка), §10. Макеты: `…/2026-10-03-gemtrack-redesign/1-obzor.html` (рейка, полоса, пульт), `7-okna-i-sostoyaniya.html` (окна, состояния). Roadmap: этап 1.

## Global Constraints

- §3.1 **Никаких прыжков**: наведение — только фон `--s2 → --s3`; выбор — `box-shadow: inset 0 0 0 1px var(--ac)`; запрещены `transform` на hover, смена `border-width`/`padding`/`font-weight` при наведении или выборе; полоса тревоги — `inset 3px 0 0 <цвет>`.
- §3.2 **Цель — только `settings.goal`** (`/api/settings`). В новом коде нет ни `2000`, ни `1000`, ни `ap.goal || …`. Нет цели — «—» и причина.
- §3.3 Четыре состояния значения: известно · `≈` + `оценка` · устарело (серее + время) · «—» + причина. Ноль и «нет данных» — разное.
- §3.4 «Накрутить» — только через окно подтверждения со списком последствий; окно **закрывается только кнопками** (не фоном, не Esc). Ключи и токены не выводятся.
- §3.5 Цифры — Geist + `tabular-nums`; Geist Mono — только id. Разряды — пробел.
- §4.1 Токены — дословно: `--bg #0c0c0e`, `--s1 #141416`, `--s2 #1b1b1e`, `--s3 #232327`, `--line #ffffff0f`, `--line2 #ffffff17`, `--ink #ecebe8`, `--ink2 #a7a5a0`, `--mute #76746f`, `--ac #b8f25c`, `--warn #f2b44a`, `--stop #ff7a7a`; радиусы 16 / 10 / 999; отступы 16 и 8; текст 12/13/15/22–24/20–34; цвет 150 мс, появление 220 мс, анимаций размера нет. Цветов смысла три.
- §4.3 `:focus-visible`, `prefers-reduced-motion`, `Tab`/`Enter`/`Space`, `Esc` закрывает окна (кроме подтверждения), подсказки и с фокуса, смысл не только цветом, подписи у кнопок-иконок.
- §4.4 Ниже 768 px рейка уходит, пункты — строкой под полосой; ниже 1100 px правая колонка уходит под страницу.
- §9.1 Проверка — **только демо** (`VITE_DEMO=1`, конфигурация `dash-demo`), живой `rig` не запускается ради дизайна.
- Roadmap-критерий: старая панель открывается как раньше; новая — по `?ui=v2` на демо; `npm run check`, `npm run build`; проверка «без прыжков» §9.3.

## Критерии, закреплённые на сверке (2026-10-04)

- **`?ui=v2` — временный переключатель на время миграции.** На этапе 9 он исчезает, старая панель удаляется целиком (вместе с `index.css` старого вида), новая открывается по `/`.
- **Функции работника в `lib/worker.ts` поведенчески идентичны прежним.** Перенос `lamp` / `pace` / `preview` / `attention` — рефакторинг, а не место менять смысл. Единственное изменение подписи — цель параметром (`attention(…, goal)`, `preview(s, goal | null)`); старая панель передаёт ровно то, что считала сама (`ap.goal || 2000`), поэтому её вывод тот же. Ветка `goal == null` в `preview` достижима только из новой панели.
- Старое окно «Настроить» на этапе 1 — **временное**, не выдаётся за новый дизайн; новый вид — этап 2.4.

## Отступления от буквы спецификации — на сверку

1. **§8 «`index.css` — переписать с нуля».** Пока жива старая панель (до этапа 9), переписывать общий `index.css` нельзя — она сломается. Поэтому стиль новой панели — отдельный `src/v2/v2.css`, все правила под `.v2`. Переписанный с нуля `index.css` появляется на этапе 9, когда старый вид удаляется.
2. **«Настроить» в пульте (§5.7).** Окно с двумя вкладками в новом стиле — это экран настроек аккаунта, он переезжает на этапе 2.4 (Аккаунты). На этапе 1 кнопка «настроить» открывает **нынешнее** окно `Tune` (работает, но в старом виде). Альтернатива — не показывать кнопку до 2.4; выбрано рабочее, но старое.
3. **Колокольчик (§5.7): «у каждой тревоги — кнопки действия».** Сейчас у тревог (`attention()` в `Work.tsx`) есть текст и «что делать», но нет действий. На этапе 1 колокольчик показывает текст и «что делать», порядок «стоп → внимание», пустое — «Всё в порядке». Кнопки действий — этап 2.1 (Обзор), где появляются сами действия.
4. **Вход** не меняется: `?ui=v2` открывается после того же входа по токену. «Тишина» — этап 7.

### Task 1: переключатель и перенос логики работника

**Interfaces — Produces:** `lamp(s: State, live: Live): Lamp`, `pace(ap): string`, `preview(s: State, goal: number | null)`, `attention(s: State, live: Live, now: number, goal: number): Alert[]` из `src/lib/worker.ts`; `AppV2` по `?ui=v2`.

- [ ] Перенести из `Work.tsx` в `lib/worker.ts` **без изменения тел**: `lamp`, `pace`, `preview`, `attention` и типы. Единственная правка — `goal` у `attention` становится параметром; `preview` при `goal == null` пишет в строке цели «— нет в настройках».
- [ ] `Work.tsx` импортирует их и передаёт `ap.goal || 2000` — **поведение старой панели не меняется** (исправлять старую панель — не задача этапа).
- [ ] `main.tsx`: `const v2 = new URLSearchParams(location.search).get('ui') === 'v2'`; `authed ? (v2 ? <AppV2 /> : <App />) : <Login />`. `AppV2` пока — пустой `<div className="v2">`.
- [ ] Проверка: `npm run check`, `npm run build`; демо `/` — Пульт выглядит и считает как до правки (снимок экрана до/после).
- [ ] Коммит `refactor: логика работника в lib/worker.ts; переключатель ?ui=v2`.
