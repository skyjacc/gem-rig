# Доступ к панели через Tailscale

Инструкция для владельца (план 7, решение 12). Каждый шаг — действие в вашей учётной записи Tailscale или на вашем ПК; выполняется **по вашему «да»**, после развёртывания этапа 7. Имена ниже — образцы: `<машина>` — имя вашего ПК в Tailscale, `<tailnet>` — имя вашей сети (видно в админке Tailscale, «DNS»).

## Что проверено по документации Tailscale (2026-10-07)

- **Адрес у того, с кем поделились машиной**, — полное имя `<машина>.<tailnet>.ts.net`; короткое имя у него не работает ([Sharing](https://tailscale.com/kb/1084/sharing)).
- **Ваши правила доступа действуют и для него**: приглашённых можно пустить только на порт 443 — `autogroup:shared` ([Sharing](https://tailscale.com/kb/1084/sharing)).
- **`tailscale serve` по HTTPS работает и для тех, кому машину расшарили** ([Serve](https://tailscale.com/kb/1312/serve)).

Следствие для панели: `serve` проксирует запросы с самого ПК, поэтому панель видит все обращения как идущие с `127.0.0.1`. Ограничения попыток «с адреса» (вход по токену, проверка ссылки-приглашения) тогда общие на всех — перебору это не помогает, приглашённому хватает.

## Шаги

1. **Панель остаётся на петле.** `HOST` не задаём — панель слушает `127.0.0.1:4322`; в сеть порт панели напрямую не открывается.
2. **HTTPS в Tailscale**: админка → DNS → включить MagicDNS и HTTPS Certificates (если ещё не включены).
3. **Проброс**: на ПК — `tailscale serve --bg --https=443 http://127.0.0.1:4322` (адрес петли явно: панель слушает `127.0.0.1`). Проверка: `tailscale serve status` показывает `https://<машина>.<tailnet>.ts.net` → `http://127.0.0.1:4322`. Синтаксис — по [документации `tailscale serve`](https://tailscale.com/kb/1242/tailscale-serve).
4. **Внешний адрес панели** — в `tools/panel.env.cmd`:
   - `set PANEL_URL=https://<машина>.<tailnet>.ts.net` — нужен входу через Steam (адрес возврата);
   - имя `<машина>.<tailnet>.ts.net` — в `ALLOWED_HOSTS` (если ещё нет);
   - после правки — перезапуск панели (по «да»).
5. **Привязать свой Steam** (вы, со своего браузера): «Аккаунты» → «Вход в панель» → «привязать свой Steam».
6. **Ограничить доступ приглашённым** — в политике доступа (ACL) правило: `autogroup:shared` → только порт 443 вашей машины.
7. **Приёмка вдвоём** — по протоколу в плане этапа 7 («Живая приёмка вдвоём»): допуск вашего тестового Steam, проверка, снятие допуска.
8. **Поделиться машиной с другом** (Share в админке Tailscale) — только после приёмки и отдельного «да», вместе с открытием входа для приглашённых и ссылкой-приглашением.

## Откат

- Закрыть вход для приглашённых — экран «Пользователи» (сессии и работа приглашённых встают сразу).
- Убрать проброс: `tailscale serve --https=443 off` (или всё сразу — `tailscale serve reset`).
- Отозвать Share в админке Tailscale.
