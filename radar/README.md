# Kinetic Radar

Go + React переписывание кинетик-радара из `tools/radar_server.js`.

Ищет на `market.dota2.net` лоты, внутри которых физически сидит кинетический гем
дороже самой вещи, и предупреждает, если во входящем обмене Steam лежит не то,
за что заплачено.

## Почему переписано

Старый `tools/radar_server.js` опрашивал маркет поиском по каждому из 12
захардкоженных предметов и не имел ограничителя частоты. У маркета жёсткое
правило: **больше 5 запросов в секунду — ключ удаляют**.

Здесь:

| | было | стало |
| --- | --- | --- |
| Частота запросов | без ограничений | один общий token bucket, 4 req/sec, тест на превышение |
| Ключ | в строке URL `?key=` | заголовок `X-API-KEY` |
| Охват | 12 предметов из списка | весь каталог маркета — 56 000+ вариантов |
| Стоимость обхода | сотни запросов к маркету | 2 запроса к маркету (`itemdb`) + Steam с кэшем |
| Свежие лоты | опрос раз в 30 сек | подписка на сокет `newitems_cs`, 0 запросов |
| Защита трейдов | нет | Trade Guard сверяет `instanceid` |

## Устройство

```
radar/
├─ backend/                 Go 1.25, одна зависимость — gorilla/websocket
│  ├─ internal/ratelimit    token bucket, единственная точка выхода в сеть
│  ├─ internal/market       клиент market.dota2.net + сокет newitems_cs
│  ├─ internal/steam        Steam Economy API + разбор сокетов
│  ├─ internal/scanner      обход каталога, оценка спреда, состояние на диске
│  ├─ internal/guard        Trade Guard
│  ├─ internal/hub          SSE-раздача событий в панель
│  ├─ internal/httpapi      HTTP API и страница инспектора
│  └─ web/                  сюда встраивается собранная панель (go:embed)
└─ frontend/                React 19 + Vite 6 + Tailwind 4
```

Сборка фронтенда кладёт файлы в `backend/web/dist`, `go build` зашивает их в
бинарник — на выходе один `radar.exe` без Node в рантайме.

## Как отличается настоящий гем от подделки

Это главное место всего проекта. У старых предметов в описании остаётся
текстовая строка вида `''Kinetic: Fireborn Assault''` даже после того, как
продавец выбил гем молотком. Парсеры, ищущие подстроку «Kinetic», покупают
пустышку.

Радар считает гемом только физический сокет: в HTML от Valve должен быть
спрайт `/sockets/gem_animation.<hash>.png`, а имя в сокете — не `Empty Socket`.
Оба случая закреплены тестами на реальном ответе Steam:
`internal/steam/testdata/assetclassinfo.json`.

## Trade Guard

Схема скама, на которой уже потеряны деньги: продавец выставляет вещь с гемом,
после продажи выбивает гем молотком. `classid` остаётся прежним, `instanceid`
меняется, кэш маркета продолжает показывать старый. Расширение авто-принятия в
браузере видит правильное название и подтверждает обмен.

Guard раз в 30 секунд читает входящие офферы через `IEconService/GetTradeOffers`
и сверяет `classid_instanceid` каждого предмета с покупками аккаунта на маркете.
Расхождение при совпадающем `classid` — критическая тревога.

**Guard ничего не принимает и не отклоняет.** Он только показывает тревогу,
решение остаётся за человеком.

## Запуск

Нужны ключи в `tools/`: `market.key` и `steam.key` (уже лежат там).

```bash
cd radar/frontend && npm install && npm run build
cd ../backend && go build -o radar.exe . && ./radar.exe
```

Панель: <http://127.0.0.1:3377/>

Разработка фронтенда с горячей перезагрузкой:

```bash
cd radar/backend && ./radar.exe
cd radar/frontend && npm run dev   # http://localhost:5177, проксирует /api
```

### Переменные окружения

| Переменная | По умолчанию | Что делает |
| --- | --- | --- |
| `RADAR_PORT` | `3377` | порт панели |
| `RADAR_KEYS_DIR` | автопоиск `tools/` | где лежат `market.key` и `steam.key` |
| `RADAR_DATA_DIR` | `radar/radar-data` | кэш обхода, чтобы рестарт не начинал с нуля |
| `RADAR_PRICES` | `tools/kinetic_prices.json` | справочник цен на гемы |
| `RADAR_ALLOW_BUY` | выключено | разрешает метод покупки (по умолчанию его нет) |

## Первый обход

Каталог маркета — около 57 000 вариантов; под фильтр цены попадает ~47 000.
Steam отвечает пачками по 100, радар шлёт 2 запроса в секунду и не больше 400 за
обход, поэтому полный первый проход занимает 5–8 минут. Результат сохраняется в
`RADAR_DATA_DIR`, дальше проверяются только новые варианты.

## Что осталось за рамками

* Покупка в один клик. Метод `Buy` в клиенте есть и требует хэш описания
  (покупка вслепую запрещена в коде), но HTTP-эндпоинта к нему нет.
* Автоотклонение обменов — сознательно не сделано.
* ShadowPay: API только для мерчантов, ключ выдаёт менеджер. Bitskins закрылся.
  Tradeit.gg, CS.Money, Buff.market — Dota 2 не поддерживают или закрыты
  Cloudflare.

## Панель

* **Попап предмета.** Клик по строке или по кнопке «Steam» открывает окно с
  разбором сокетов: спрайты Valve, тип каждого сокета, что в нём лежит. Ниже —
  живые предложения о продаже и ордера на покупку, а также сворачиваемый
  оригинальный блок Steam. Закрывается по Esc или клику по фону.
* **Иконки.** Артворк предметов берётся из Steam Economy CDN, портреты героев —
  из CDN Dota 2 по `heroid` из каталога маркета (карта id → герой встроена в
  бинарник, `internal/dota/heroes.json`). Иконки сокетов — оригинальные спрайты
  Valve. Собственные SVG нарисованы для радара, гема, пустого сокета, молотка и
  рубля; интерактивные иконки — Lucide с микро-анимациями по наведению.
* **Цвет редкости.** Название предмета и рамка иконки красятся в цвет редкости
  Dota (Immortal, Arcana, Mythical и т.д.).
* **Таблица.** Поиск по предмету, гему и герою; сортировка по цене лота, цене
  гема, спреду и ROI.
* **График.** Топ спредов: красная часть — цена лота, зелёная — цена гема, зазор
  между ними и есть прибыль. Клик открывает попап.
* **Уведомления.** Тосты в углу вместо блокирующих окон, звук находки с
  переключателем (состояние запоминается в браузере).

> Цена гема считается по минимальному предложению о продаже. В попапе видно и
> лучший ордер на покупку — иногда он в разы ниже, и тогда спред в таблице
> оптимистичен. Если нужно, могу считать спред по ордерам.

## Откуда берутся цены на гемы

Цена гема — **медиана по пяти независимым рынкам**, а не аск одного продавца.
Это главный урок первых прогонов: один оптимист держал `Twin Deaths' Haunting`
за 150 ₽, и радар рисовал по нему ROI 400%. Реальные сделки DMarket по тому же
гему — 6 ₽.

| Источник | Ключ | Что даёт | Гемов |
| --- | --- | --- | --- |
| market.dota2.net | есть | аск, уровень варианта | 51 |
| **DMarket** | есть | **реальные проданные цены**, уровень варианта, готовые сокеты | 51 |
| Steam Market | не нужен | аск + `volume` продаж | 45 |
| LOOT.Farm | не нужен | аск + `max` = сколько готовы принять | 32 |
| Waxpeer | не нужен | аск + число лотов | 28 |
| Lis-Skins | не нужен | аск по 75 000 отдельных лотов | 13 |

Правила оценки в [`internal/pricing`](backend/internal/pricing/book.go):

* Завершённая сделка перебивает любые аски — это единственное число, которое
  кто-то заплатил.
* Разброс между рынками больше **8 раз** — доверие всегда «слабое», сколько бы
  источников ни было. Так `Northlight Illuminance` (7 ₽ на одном рынке, 239 ₽ на
  другом) перестаёт выглядеть надёжной находкой.
* Три и более рынка в пределах 2 раз — «надёжно». Один источник — «слабо».

Курс доллара берётся из самого Steam: один и тот же гем запрашивается в USD и в
RUB, отношение и есть курс. Никакой внешней валютной API.

Лоты, которые сами являются гемом (`Kinetic: …` или `Кинетический: …`), в
находки не попадают — покупать гем, чтобы достать гем, смысла нет.

## Две площадки для поиска

| | market.dota2.net | DMarket |
| --- | --- | --- |
| Как ищем | каталог `itemdb`, сокеты сверяем в Steam Economy API | пагинация офферов, сокеты приходят разобранными |
| Запросов к Steam | ~570 на первый полный обход | **ноль** |
| Обход | минуты | ~5 секунд на 2 000 офферов |
| Trade lock | не сообщает | `lock_days` в карточке |

## Откуда берутся цены на гемы

`tools/kinetic_prices.json` (48 позиций) используется только как стартовое
значение. В каждом обходе радар видит сами гемы, выставленные на продажу
(их название начинается с `Kinetic:`), и берёт минимальную цену лота как
текущую стоимость гема — в первом же обходе это около 50 позиций по живому
рынку. Такие лоты никогда не попадают в находки: покупать гем, чтобы достать
гем, смысла нет.
