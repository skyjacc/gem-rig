# Архив исходных измерений

`_sets-2026-08-19.pkl` — Python-pickle, `{имя гема → множество match_id}`,
47 гемов, 64 799 строк, объединение 40 342.

Это первое измерение запаса, сделанное 19 августа выгрузкой из OpenDota
с фильтром `lobby_type = 1`. Все числа «было» в README и в спеке взяты отсюда.

Датасет **устарел и неверен**, хранится только как доказательство:

- фильтр втягивал турнирные лобби без записи о лиге, а такие матчи
  отправить нельзя вовсе — `league_id` обязателен
- для части игроков эндпоинт молча отдавал пусто, и это записывалось
  как «запас ноль» (Ohaiyo, iceiceice, Era и ещё семеро)

Актуальные данные — в таблицах `vmatch` и `vplayer` базы `rig.db`,
собранных обходом Steam Web API и добором из OpenDota.

Читать только ограниченным Unpickler: формат допускает исполнение кода.
