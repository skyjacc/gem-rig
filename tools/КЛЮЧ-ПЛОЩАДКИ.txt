Ключ market.dota2.net кладётся сюда:

    tools/market.key

Один файл, внутри только сам ключ, ничего больше — ни кавычек, ни имени
переменной, ни перевода строки в начале.

Взять его: market.dota2.net → войти → Настройки → API → создать ключ.

Панель подхватит его при следующем запросе, перезапускать ничего не надо.
В репозиторий файл не попадёт: он перечислен в .gitignore рядом с ключами
Steam и OpenDota.

Проверить, что ключ виден: на вкладке «Скупка» в сводке появится баланс
вместо «нет ключа».

Можно и переменной окружения MARKET_KEY, если так удобнее — она имеет
приоритет над файлом.
